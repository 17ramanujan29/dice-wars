# dice-wars

## さいころで領土を支配するゲーム

基本ルール
大まかな流れは通常のDice Warsと同じ

ターン終了時、連続領土数の3分の2を切り上げた数だけダイスが付与される

一つの領土におけるダイスの数は最大8個

---

ローカルルール

2人、3人、4人プレイの時のマップの合計領土数と、最初のダイス付与の仕様は以下の通り。自分が何番目にプレイするかで最初のダイス付与数が違うことに注意。（先手有利是正）
2人プレイ　マップ全体で28領土　1番目は42ダイス、2番目は46ダイス
3人プレイ　マップ全体で27領土　1番目は30ダイス、2番目は33ダイス、3番目は36ダイス
4人プレイ　マップ全体で28領土　1番目は22ダイス、2番目は24ダイス、3番目は26ダイス、4番目は28ダイス

攻撃が失敗したときは、攻撃した側のダイスの量を切り上げ半減（攻撃不利是正）

引き分け時は、攻撃側と防御側のダイスの量をどちらも切り捨て半減（攻撃不利是正）

連続領土が5以下のプレイヤーは、自分のターン終了時のダイスが4個付与される（ジリ貧是正）

連続領土が14以上のプレイヤーは、（ジリ貧是正）

---

ターミナル操作
npm run dev : 開発サーバーを立ち上げる。停止したいときはctrl + c　を押し、y を入力してenterを押します。
npm run build : ファイル分割を1つにまとめた最終コードがdistリポジトリにindex.htmlとして生成される

改善案

## オンライン対戦

PeerJS Cloudを利用したオンライン対戦に対応しています。開始画面で「オンライン対戦」を選び、ホストは「ルームを作成」、参加者はホストから共有されたルームコードを入力して参加します。

ロビーでは最大4人まで参加でき、現在の参加人数を表示します。参加者が2〜4人になった時点でホストがゲーム開始を押すと、その時点の人数で対戦人数を確定します。ゲーム中の盤面、乱数、戦闘結果、ターンはホストが管理し、参加者の操作要求を検証して全端末へ同期します。

複数端末で試す場合は、各端末から同じ開発サーバーへアクセスできるネットワーク設定が必要です。PeerJS Cloudとの接続には、公開環境ではHTTPSを使用してください。現在の初期仕様ではホストまたは参加者が切断するとオンラインセッションを終了します。途中再接続、ホスト移譲、CPU引き継ぎにはまだ対応していません。
